# Verify Certificate Web Application

A web application to verify certificates using a hash and username. This project is designed with a modern UI and leverages a robust tech stack for seamless functionality.

## Features

- **Certificate Verification**: Users can input a hash and username to verify certificates.
- **Responsive Design**: Optimized for various screen sizes.
- **Interactive UI**: Includes hover effects and animations for an engaging user experience.

## Tech Stack

### Frontend
- **HTML5**: For structuring the web pages.
- **CSS3**: For styling and layout design.
- **JavaScript**: For client-side interactivity.

### Backend
- **Node.js**: For server-side scripting.
- **Express.js**: For building the web application framework.

### Database
- **CockroachDB**: For database management.

## Installation

1. Clone the repository:
   ```cmd
   git clone https://www.github.com/5C3PT3R/vcert
   ```
2. Navigate to the project directory:
   ```cmd
   cd vcert
   ```
3. Install dependencies:
   ```cmd
   npm install
   ```
4. Start the server:
   ```cmd
   npm start
   ```

## Usage

### MAIN

1. Open `index.html` in a browser.
2. Register and Login.
3. Upload and delete pdf files.

### VERIFY

1. Open `verify.html` in a browser.
2. Enter the hash and username in the form.
3. Click "Verify" to check the certificate.
